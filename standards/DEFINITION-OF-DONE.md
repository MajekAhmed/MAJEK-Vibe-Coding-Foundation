# Definition of Done
- [ ] Acceptance criteria are explicit and met.
- [ ] Changes stayed within approved scope.
- [ ] No secrets or unrelated files were added.
- [ ] Relevant lint/type/tests/manual checks ran.
- [ ] Commands, results, and limitations are recorded.
- [ ] Edge cases and failure paths were considered.
- [ ] Documentation and handoff are updated.
- [ ] No unapproved deployment or destructive action occurred.

If a check was not run, mark it NOT RUN.
