# Security Baseline
- Secret scanning before sharing/publishing.
- Dependency vulnerability review for package changes.
- Language-appropriate static analysis.
- Least privilege for agents, tokens, MCP servers, and CI.
- Review third-party skills/plugins/MCP servers before adoption.
- Treat downloaded code and generated commands as untrusted until inspected.
- Validate with disposable fixtures and synthetic data.
- Record scanner versions, commands, results, and exclusions.

Status: policy defined; automated scanners and CI gates not yet installed or validated.
