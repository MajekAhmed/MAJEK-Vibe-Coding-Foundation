# Foundation Agent Rules
1. Work only inside this repository unless explicitly authorized otherwise.
2. Do not inspect or modify H:, partitions, production systems, or unrelated projects.
3. Read the Safety Policy before acting.
4. Default to read-only; ask before installs, system changes, external side effects, or destructive actions.
5. Never expose or store secrets.
6. Do not add project-specific frameworks, dependencies, or assumptions.
7. Prefer portable Markdown standards before automation.
8. Separate facts, assumptions, and recommendations.
9. Report commands and observed validation evidence.
10. If scope is ambiguous, stop and ask.
